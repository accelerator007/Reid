# موقع رِيْد — Reid

الموقع التعريفي لشركة رِيْد التقنية: منتجات برمجية، استشارات تقنية، وحلول ذكاء اصطناعي وإنترنت أشياء لقطاعي الطاقة والصحة.

موقع ثابت (Static) بلا أي إطار عمل أو خطوة بناء — HTML و CSS و JavaScript خام فقط. سريع، خفيف، وسهل الاستضافة على أي مزوّد ملفات ثابتة.

## التطوير محليًا

الموقع ثابت، فأي خادم ملفات يكفي:

```bash
python3 -m http.server 4173
# ثم افتح http://localhost:4173
```

> ملاحظة: الروابط والمسارات مطلقة (تبدأ بـ `/`)، لذا شغّلوه من جذر المشروع لا من مجلد فرعي.

## النشر

### Cloudflare Pages أو Netlify (موصى به)
1. ارفعوا المستودع إلى GitHub.
2. أنشئوا مشروعًا جديدًا واربطوه بالمستودع.
3. الإعدادات: **بلا أمر بناء (No build command)**، ومجلد الإخراج هو الجذر (`/` أو `.`).
4. ملف `_headers` و`404.html` يُلتقطان تلقائيًا.

### GitHub Pages
- فعّلوه من Settings → Pages، الفرع `main` والمجلد `/ (root)`.
- (ملف `_headers` لا يعمل على GitHub Pages؛ التخزين المؤقت يُدار افتراضيًا.)

### النطاق
- اربطوا `reidpro.com` (المستخدم في البريد) بالموقع، وفعّلوا HTTPS.
- بعد الربط، جميع الوسوم (`canonical`, `og:url`, `hreflang`, `sitemap`) تشير مسبقًا إلى `https://reidpro.com` فتعمل مباشرة.

## بعد الإطلاق — خطوات مطلوبة

هذه العناصر جاهزة في الكود لكنها تحتاج قيمًا حقيقية:

1. **نموذج التواصل**: يرسل عبر [FormSubmit](https://formsubmit.co) إلى `contact.us@reidpro.com`. أول إرسال يتطلّب تفعيلًا لمرة واحدة عبر رابط يصل بريدكم. يعمل بلا حساب، ويسقط تلقائيًا إلى بريد `mailto` عند فشل الشبكة.
2. **روابط التواصل الاجتماعي**: لينكدإن مربوط بالحساب الفعلي (`linkedin.com/company/135245905`). أما X و GitHub (`x.com/reidpro`, `github.com/reidpro`) فما زالا مؤقتين — استبدلوهما بالحسابات الفعلية أو احذفوا ما لا يوجد.
3. **التحليلات**: كتلة Plausible معطّلة في `<head>`. فعّلوها بعد إنشاء حساب وربط النطاق (تحترم الخصوصية وبلا كوكيز). دوال التتبع في `script.js` جاهزة لأحداث التحويل (نموذج، واتساب، أزرار CTA).
4. **قسم الشهادات**: هيكله جاهز ومعطّل في `index.html`؛ فعّلوه بعد جمع شهادات موثّقة بأسماء أصحابها.
5. **الأرقام**: تأكّدوا أن إحصائيات الصفحة الرئيسية (+40 مشروعًا، +25 عميلًا، 98% رضا) قابلة للدفاع عنها.
